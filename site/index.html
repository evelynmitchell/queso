Queso

A formally-checked implementation of the QuePaxa consensus algorithm.

Built ground-up and test-driven in Rust: a deterministic simulation kernel, a single-slot consensus core, multi-slot state-machine replication, and a real-TCP node — with a testing surface that runs from property tests and TLA+ model checking to real-process fault-injection soaks with post-mortem adjudication.

The repository README is the canonical front door; this site publishes the same documentation in rendered form.

Crates

  • queso-sim — deterministic discrete-event simulation kernel; no consensus logic.
  • queso-consensus — abstract single-slot QuePaxa consensus: proposer, recorder, the interval summary register.
  • queso-smr — multi-slot replicated log driving a linearizable KV store, with crash-recovery and leader tuning.
  • queso-net — the real-I/O node: TCP transport, TLS, durable persistence, the queso-node binary.
  • queso-chain — the Chain-of-Blocks (n, h) hash chain over an applied command sequence.
  • queso-conformance — in-process Chain-of-Blocks conformance workload plus divergence/liveness observers.
  • queso-soak — real-process soak harness: seeded fault schedules, evidence preservation, post-mortem adjudication.
  • queso-compare — common workload/metrics harness comparing Queso against etcd/Raft.
  • queso-antithesis — the conformance workload packaged as an Antithesis test template.
